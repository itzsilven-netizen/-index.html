# Upgrade the Copy

Rewrite the marketing copy in `$ARGUMENTS` (e.g. `/upgrade-copy hero` or `/upgrade-copy why-us` or `/upgrade-copy all`).

## What to do

1. Read `index.html` in full.
2. Target the section(s) specified — or all sections if `all` is passed.
3. Rewrite headlines, subheadlines, body copy, and CTAs to be:
   - **Bolder and more specific** — replace generic claims with concrete, measurable outcomes
   - **Benefit-first** — lead with what the client gains, not what Apex Standard does
   - **Urgency-driven** — use scarcity, time, or loss-aversion framing where appropriate
   - **Consistent voice** — premium, confident, direct; never salesy or buzzword-heavy
4. Keep all HTML structure, class names, and `id` attributes identical — only change text node content.
5. Do NOT change prices, Calendly links, or any attribute values.
6. After editing, list the sections changed and the core message improvement for each.
